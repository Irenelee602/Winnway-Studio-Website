Winnway Studio V4
=================

使用方式
1. 雙擊 index.html，即可在瀏覽器開啟。
2. 搜尋可顯示各年份價格。
3. 酒款比較可分別選擇酒款與年份。
4. 百科內容與酒款資料皆可從開發者後台新增。
5. 右上角「我的酒窖」可直接管理藏酒數量、存放位置與備註。
6. 從任一酒款詳細頁按「加入我的酒窖」即可新增，不需進入後台。
7. 點擊「問侍酒師」，輸入餐點、場合、預算或偏好，即可取得酒款推薦與理由。

開發者後台（展示用）
1. 在網址最後加上 #developer，例如：index.html#developer
2. 開發者代碼：preview2026
3. 新增資料會保存在目前瀏覽器，不會上傳到網路。

重要說明
- 一般頁面沒有後台入口。
- 此 V2 的登入是介面與流程佔位，不是真正的伺服器安全驗證。
- 正式公開上線前，需串接資料庫、身分驗證與伺服器權限控管。
